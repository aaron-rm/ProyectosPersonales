# Tic-Tac-Toe (Tres en Raya, X-O) en Python

Este es un juego de **Tic-Tac-Toe** (Tres en Raya, X-O) esarrollado en Python utilizando la biblioteca **Tkinter**. El juego permite partidas locales entre dos personas o contra una Inteligencia Artificial imbatible.

## 🌟 Características

* **Interfaz Gráfica (GUI):** Diseño con tema oscuro, tipografía y colores contrastantes.
* **Modos de Juego:**
    * **Jugador vs Jugador:** Dos personas pueden jugar en el mismo equipo por turnos.
    * **Jugador vs Computadora:** Enfréntate a una IA que utiliza el algoritmo **Minimax**.
* **IA Imbatible:** La computadora analiza todas las posibilidades para asegurar que nunca pierda.
* **Sistema de Puntaje:** El juego lleva el registro de victorias de 'X' y 'O' durante la sesión (depende del modo de juego).
* **Gestión de Turnos:** Indicadores visuales claros para saber a quién le toca mover.

## 🛠️ Requisitos

Para ejecutar este juego, solo necesitas tener instalado **Python 3**. La biblioteca `tkinter` suele venir incluida por defecto en la instalación estándar de Python.

## 🚀 Cómo empezar

1. **Clona o descarga** este repositorio.
2. Abre una terminal o consola en la carpeta del proyecto.
3. Ejecuta el script con el siguiente comando:
   ```bash
   python tictactoe.py
